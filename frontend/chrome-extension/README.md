# ZUKA Site Sound Sync

This small Chrome extension lets the ZUKA Sound alerts switch read and update Chrome's site-level Sound permission for the local app.

## Install in Chrome

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked** and select this `chrome-extension` folder.
4. Reload the ZUKA page at `http://localhost:5173`.

After installation, the ZUKA Sound alerts switch follows Chrome's current site Sound setting. Switching it off blocks site sound in Chrome; switching it on allows site sound. Without the extension installed, the switch only controls ZUKA's own alert chimes.
